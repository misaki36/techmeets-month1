# コメント投稿フォーム 

## 概要

PHPで作成したコメント投稿フォーム。  
`comment.php` にあったバグを発見・修正し、`comment_fixed.php` として保存した。

---

## 見つけた問題点

### 問題1: 比較演算子のミス
```php
// 修正前
if ($name = "") {
```
`=` は代入演算子のため、`$name` に空文字が代入されて常に `false` になり、  
名前が空でも空チェックが機能しない状態だった。

---

### 問題2: ユーザー入力をそのまま出力している（XSS脆弱性）
```php
// 修正前
echo "<p>" . $name . "さんのコメント:</p>";
echo "<p>" . $comment . "</p>";
```
ユーザーが入力した値を `htmlspecialchars()` なしで直接 echo しているため、  
悪意のあるスクリプトが実行されてしまう可能性があった（XSS攻撃）。

---

### 問題3: `$_POST` のキー存在チェックがない
```php
// 修正前
$name    = $_POST["name"];
$comment = $_POST["comment"];
```
フォームが送信されていない状態でキーにアクセスすると、  
`Undefined index` の Warning が発生する可能性があった。

---

## 修正した箇所

### 修正1: 比較演算子を正しく使う
```php
// 修正後
if ($name == "") {
```
`==` を使って値の比較を行うように修正した。

---

### 修正2: `htmlspecialchars()` でエスケープ処理を追加
```php
// 修正後
echo "<p>" . htmlspecialchars($name) . "さんのコメント:</p>";
echo "<p>" . htmlspecialchars($comment) . "</p>";
```
ユーザーの入力値を出力する際に `htmlspecialchars()` でHTMLの特殊文字をエスケープし、  
XSS攻撃を防ぐようにした。

---

### 修正3: Null合体演算子で安全に取得する
```php
// 修正後
$name    = $_POST["name"] ?? "";
$comment = $_POST["comment"] ?? "";
```
`??` (Null合体演算子) を使い、キーが存在しない場合は空文字を代入するようにした。

---

## 学んだこと

- `=` と `==` の違い。代入と比較を混同するとバグの原因になる。
- ユーザーの入力値は必ず `htmlspecialchars()` を使う。
- `$_POST` や `$_GET` のキーに直接アクセスする前に、存在チェック (`isset()` や `??`) を行う。
- セキュリティ（XSS対策）は忘れずに必ず組み込んでおくことが大事。
