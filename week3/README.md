# Week3 振り返り

## 今週学んだこと

- **JavaScript読解**  
  既存のコードを読み解く練習を通じて、変数・関数・イベント処理の流れ。  
  どこで何が起きているかをコードから追う。

- **PHPの基礎**  
  フォームからのデータ受け取り（`$_POST`）、条件分岐、画面への出力など基本的な処理を学んだ。  
  また、セキュリティ対策として `htmlspecialchars()` によるXSS防止や `??` を使った安全な値を使う。

---

## 難しかった点

- JavaScriptはコードの流れが追いにくく、どこで変数が使われているか把握するのに時間がかかった。
- PHPで `=`（代入）と `==`（比較）を混同してしまい、バグの原因に気づくまで時間がかかった。
- セキュリティ（XSS対策）は意識しないと見落としやすく、なぜ必要なのかを理解するのが難しかった。
- 英語が苦手すぎて単語の意味がわからなかったり、分かったとしても説明文として正しく翻訳できなかったりして読解するのに時間がかかった。



---

## 次に活かしたいこと

- コードのパターンを地道に覚えておき、ノートに逐一記載する。
- PHPで条件分岐を書くときは `=` と `==` を必ず確認する癖をつける。
- ユーザー入力を扱うときは `htmlspecialchars()` と存在チェック（`??` や `isset()`）をセットで使うことを習慣にする。
